행렬 경로 문제 — 동적 계획(DP) 시뮬레이션

c 표가 한 칸씩 채워지는 과정과, 표를 거꾸로 따라가 최적 경로를 찾는 과정을 단계별로 봅니다.

문제

양수 원소로 된 n×n 행렬의 왼쪽 위 (1,1)에서 출발해 오른쪽 아래 (n,n)까지 갑니다.
  • 오른쪽이나 아래쪽으로만 움직일 수 있습니다. 왼쪽·위쪽·대각선 이동은 안 됩니다.
  • 목표: 지나간 칸의 수를 모두 더한 값이 가장 크게 되는 경로를 찾습니다.
  • c[i, j] = (1,1)에서 (i, j)까지 오는 경로들 중 최고 점수 → c[i, j] = mij + max(c[i-1, j], c[i, j-1])

왼쪽 행렬의 숫자는 눌러서 바꿀 수 있습니다(1~99). 키보드: ← → 이동, Space 자동 재생. «직접 계산해 보기»를 켜면 다음 칸의 c 값을 먼저 입력해야 넘어갑니다.

입력 행렬 m

지나간 칸의 수를 더합니다

DP 표 c

0행·0열은 행렬 밖(경계), 값은 0
지금 채우는 칸 비교하는 두 칸 더 큰 쪽 최적 경로

DP 알고리즘 (지금 실행 중인 줄)

matrixPath(n)   ▷ (n, n)에 이르는 최고점수{  for i ← 0 to n      c[i, 0] ← 0;  for j ← 1 to n      c[0, j] ← 0;  for i ← 1 to n      for j ← 1 to n          c[i, j] ← mij + max(c[i-1, j], c[i, j-1]);  return c[n, n];}

마지막의 «경로 되짚기»는 위 코드에는 없는 추가 단계입니다. 최고 점수만이 아니라 실제 경로도 알고 싶을 때, c[n, n]에서 위·왼쪽 중 더 큰 칸을 따라 (1, 1)까지 거꾸로 갑니다.

재귀로 풀면 몇 번 호출할까?

matrixPath(i, j){  if (i = 0 or j = 0) then return 0;  else return mij + max(matrixPath(i-1, j), matrixPath(i, j-1));}

«재귀 호출 횟수»를 켜면 c 표 각 칸 오른쪽 아래에, 재귀 알고리즘이 그 칸을 몇 번 다시 계산하는지 주황색으로 보여 줍니다. DP는 모든 칸을 한 번씩만 계산합니다.
